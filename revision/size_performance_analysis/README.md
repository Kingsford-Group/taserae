# Size vs performance

Per-class F1 of TASER-AE at augmentation multipliers from 0.01X to 10X, three seeds.

```bash
python3 revision/size_performance_analysis/run_size_analysis_per_class.py
```
Run from the repository root. The device and multipliers are set at the top of the script.
Results and figures go to `revision/size_performance_analysis/outputs/`.
